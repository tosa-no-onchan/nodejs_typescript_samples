# nodejs_typescript_samples/mqtt_iot/server_iot

node.js + express + typedcript + ejs サーバーサイド プログラム  
mqtt_iot/server_iot  

### git clone this repository  
$ git clone ....  
$ cd nodejs_typescript_samples/mqtt_iot/server_iot  
  
### package install  
  
package.json を使って、一括インストールします。  
$ npm install  
  

### build  

$ npx tsc  

#### 先に、 docker での mqtt と、クライアン側を起動しておきます。  
  
### run  
$ node dist/index.js  

### browzer  
htp://localhost:3000/
